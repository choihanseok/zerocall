## Impact / Plan

1. 공통 AUTH에 PasswordHashAdapter Protocol과 Argon2id 구현만 추가한다.
2. argon2-cffi의 RFC 9106 low-memory 프로파일을 명시적으로 사용한다. 무작위 salt는 라이브러리가 발급한다.
3. 입력 형식과 계산 자원 상한을 검증하고 오류 원문을 외부 예외 메시지로 전파하지 않는다. 비밀번호나 해시를 로그·파일·DB에 기록하지 않는다.
4. 실제 알고리즘 왕복/불일치/무작위 salt/Unicode/재해시/잘못된 입력/과도한 비용/오류 마스킹을 검증한다. 기존 전체 테스트·lint·wheel build도 실행한다.
5. 요구사항·보안·테스트 보충 문서와 보고서를 동기화한다. 독립 브랜치와 후속 PR로 게시한다.
