- Domain/DB: 계정 ID, 다섯 상태코드, created_at/updated_at/deleted_at의 최소 foundation schema.
- phone/email/password_hash/인증 및 로그인 시각: 이번 기능 범위 밖으로 NOT_IMPLEMENTED. 향후 추가 Migration 필요. 가입정책을 우회하는 공개 생성 API 없음.
- API/UI/Role/Permission/Finance/External/Notification: 변경 없음.
- Audit: 상태변경/탈퇴 기능 없음. 내부 생성은 commit 후 이벤트 로그와 생성시각으로 확인. 정식 Audit/관리자 기능은 이번 범위 밖.
- Migration: accounts 신규 테이블 및 status index, PK, status enum CHECK, 시각 순서 CHECK. 기존 데이터 삭제/수정 없음.
- 호환성: 기존 business schema가 없음. 다른 테이블이 있을 경우 그대로 보존 검증.

## 구현 순서

1. 불변 Account Entity 및 AccountStatus.
2. Repository Protocol과 SQLAlchemy 구현(생성/조회만, transaction commit 및 실패 rollback).
3. 내부 Service Base(입력 UUID 검증, PENDING 생성, 누락 오류). 인증이나 역할 기능을 노출하지 않음.
4. additive Migration. 자동 create_all/schema sync 사용 금지. downgrade는 데이터 보존을 위해 거부.
5. Unit(정상/오류/상태/불변성), Integration(영속성, 중복/동시성, 실패 rollback, soft-deleted 조회 차단, migration 재실행/기존 데이터 보존) 및 Bootstrap Regression/Build/Lint.
6. DB/Status/API/Test 동기화, 최종 보고서, GitHub에 검토 가능한 변경 저장 후 중지.
